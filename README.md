# Customer-shopping-Behaviour-Dashboard
Customer Shopping Behaviour Dashboard using python/pandas, SQL,Powerbi

## About the Project

This is an end-to-end data analytics project based on customer shopping behaviour.

I worked on the project from data cleaning to business analysis and dashboard creation using Python, SQL, and Power BI.

## Tools Used

- Python
- Pandas
- MySQL
- Power BI
- DAX

## What I Did

### 1. Data Cleaning – Python & Pandas
- Checked and handled missing values
- Checked duplicate records
- Cleaned and prepared the data for analysis
- Performed basic data transformations

### 2. Business Analysis – SQL
- Connected the cleaned data with MySQL
- Wrote SQL queries to answer business questions
- Analyzed sales, revenue, customer behaviour, categories, and age groups

### 3. Dashboard – Power BI
Created an interactive dashboard to present the analysis.

The dashboard includes:
- Number of Customers
- Average Purchase Amount
- Average Review Rating
- Subscription Status
- Revenue by Category
- Sales by Category
- Revenue by Age Group
- Sales by Age Group
- Gender and Shipping Type analysis

## Project Outcome

This project helped me practice the complete data analyst workflow:

**Data Cleaning → SQL Analysis → Business Insights → Power BI Dashboard**

It also helped me understand how to turn raw customer data into useful information for business analysis.
